# Guest OS icons

These local images identify the guest OS reported by Nex Core. Match Linux
guests by the exact `/etc/os-release` `ID`, and other guests by the exact OS ID
reported by the agent (for example, `windows` or `mswindows`). Do not infer an OS
from a display name, `ID_LIKE`, or a related distribution. Display images in a square box with
`object-fit: contain`, preserving source proportions. The direct asset links
below identify provenance; unresolved copyright or trademark terms are recorded
for release review, as directed by the project owner.

## Retained notices

- `COPYING-amazon` retains the Amazon Linux logo package's complete restrictive terms.
- `COPYING-ubuntu`, `COPYING-oracle`, and `COPYING-mx` retain source-package copyright terms.
- `COPYING-kali`, `COPYING-linuxmint`, and `COPYING-linux` retain upstream notices and attribution.
- `COPYING-nobara-logos`, `LICENSE-bazzite`, and `LICENSE-garuda-icons` retain respective package/repository terms.
- `LICENSE-GPL-3.txt`, `LICENSE-CC-BY-4.0.txt`, `LICENSE-CC-BY-SA-3.0.txt`, and `LICENSE-CC-BY-SA-4.0.txt` contain the retained license texts. Follow other attribution and linking conditions in the catalogue.

The Windows Fluent UI path data, Devuan favicon and Nobara image are displayed with a theme-aware contrast treatment. The AlmaLinux and CentOS SVGs had non-rendering editor metadata removed; their visible paths and colors are unchanged. Arch is the current official favicon, not the former crystal mark. These third-party marks are guest identifiers, not Nex branding or endorsements. Keep unresolved copyright/trademark terms in release review; an official public download alone is not a grant.
