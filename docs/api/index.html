Nex Controller and Core API — 0.1.0

Development HTTPS JSON API v1; Controller/Core protocol version 1 only. Administrator sessions and host-scoped outbound mutual-TLS reports are separate trust surfaces. Includes idempotent appliance environment bootstrap, adoption and read-only managed appliance inventory; host-local operations have a separate contract in local-openapi.json. No central VM mutations or console streams.

POST /api/v1/session

Sign in as administrator

Validates existing administrator credentials and browser origin. Sets __Host-nex_session with Secure, HttpOnly, SameSite=Strict, Path=/ and no Domain. Each login creates a new session; at most 64 active sessions per service. Sessions expire after 30 minutes without an authenticated mutation and eight hours absolutely; GET/HEAD polling does not renew them. Legacy unprefixed cookies are not accepted; sign in again after upgrade. Existing password hashes remain valid; new administrator bootstrap passwords must be nonempty valid UTF-8, at most 1024 UTF-8 bytes, without CR, LF or NUL; there is no minimum length or complexity rule. Login admission permits at most five valid-length attempts per one-minute actual peer-IP window, two concurrent password checks per service, and 4096 tracked peers. Forwarded client-IP headers are ignored. Login returns 429 when rate/concurrency/table or 64-session capacity is exhausted; bounded retries must not create an unbounded loop.
