# Nex Core 0.2.9 release verification

## Scope

This report records the exact local artifact checks and public publication status for Nex Core
0.2.9. It supplements the feature-specific evidence linked from the applicable change records.

## Environment and method

- Source: current uncommitted worktree on 2026-09-16.
- Version source: newest numbered `CHANGELOG.md` heading, resolved by
  `python3 scripts/release-version.py --current --format both`.
- Build: `installer/build.sh`, which rebuilds the Controller appliance, Nex packages and ISO.
- Publication: not attempted until the local artifact passes its release checks and the external
  distribution requirements in `docs/LICENSING.md` are satisfied.

## Limits

This report does not certify whole-ISO redistribution, physical hardware, the open Windows
TPM/Secure Boot requirements matrix, or the unresolved historical BUG-0213 timing gap. Public ISO
publication remains blocked by the complete component/source manifest, tested corresponding-source
delivery, firmware-term review and Nex artwork redistribution decision required by
`docs/LICENSING.md`. Release automation does not satisfy or enforce those gates by itself.
