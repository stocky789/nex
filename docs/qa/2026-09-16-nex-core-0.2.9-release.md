# Nex Core 0.2.9 release verification

## Scope

This report records the exact local artifact checks and public publication status for Nex Core
0.2.9. It supplements the feature-specific evidence linked from the applicable change records.

## Environment and method

- Environment: disposable local QEMU and source-artifact inspection. This record deliberately
  omits workstation and lab identifiers.
- Version source: newest numbered `CHANGELOG.md` heading, resolved by
  `python3 scripts/release-version.py --current --format both`.
- Build: `installer/build.sh` rebuilt the Controller appliance, Core package and ISO;
  `packaging/controller/build.py` built the matching standalone Controller package.
- Publication: copied to the dedicated website publisher over its existing authenticated SSH
  path, then published with the same APT and download-tree commands used by the release workflow.

## Results

- Version resolution: `0.2.9 0.2.9`.
- Final ISO: `nex-core-0.2.9-amd64.iso`, 2,045,181,952 bytes, SHA-256
  `4c44133a004eaacddee9644717ba96030429021644f0b1c5cef1aaf42402f2b9`.
- Corresponding-source bundle: 2,110,088,493 bytes, SHA-256
  `eba9a4308dd2c019a3006514dbd16df1f378236ab58a03267b22687bb62a9679`.
- Compliance manifest: 643,630 bytes, SHA-256
  `78237830513200dae6ce808a8dd69991fd861afcd57e7bfb3b3d3035cffb9a25`.
- `nex-core-local` SHA-256:
  `2011f0df6dc7aa8dd0478d0d1ac68701164b86c70e61d7a7c51a0819a11cf393`.
- `nex-controller` SHA-256:
  `91227b02231315707d2277198b19ffabcbbe72ba2a3911a92749f3308493728d`.
- All three SHA-256 sidecars passed, and the compliance manifest bindings matched the final ISO
  and corresponding-source bundle.
- The final ISO contains 1,262 `.deb` and `.udeb` components and none of the six excluded
  firmware packages. The Controller appliance adds 323 package records, for 1,585 total records.
- The final ISO contains no `virtio-win` media. Automatic bundling stays open until the exact
  corresponding sources and notices for every embedded component are retained.
- Exact retained source covers all 573 required source-package/version pairs; each retained
  `.dsc` payload passed SHA-256 validation. The manifest names 725 extracted package notices plus
  the four Nex license/notice paths, and every named source-bundle notice exists. Its 44-file
  release recipe exactly matches the media/source/publisher tooling used for this artifact, and
  archive ownership metadata is normalized.
- The ISO `md5sum.txt` verification and `installer/check.sh` both passed. The latter covered
  boot menus, syntax, interactive configuration, package inputs and offline APT assertions.
- 104 focused release, source-delivery, package and installer checks passed. The shared tree also
  passed 286 Python tests, `go test ./...`, and the web typecheck, unit tests and production build.
- Final-ISO BIOS and UEFI QEMU menu checks passed under TCG. Visual inspection of the captures
  confirmed all four entries: GUI, minimal text, serial console and rescue.
- The final ISO completed an unattended offline UEFI installation under TCG, then first boot and
  reboot from the installed disk. Serial evidence emitted `NEX_SMOKE_INSTALL_PASS`,
  `NEX_SMOKE_OVMF_2023_CERTIFICATES_PASS`, `NEX_SMOKE_ROOT_ONLY_PASS`,
  `NEX_SMOKE_IDENTITY_PASS`, `NEX_SMOKE_FIRST_BOOT_PASS`, and `NEX_SMOKE_REBOOT_PASS`.
  A first-boot harness attempt hit the host Unix-socket path-length limit before the guest service
  ran; resuming the same installed disposable disk from a shorter path completed both checks.
- Public website verification passed on 2026-09-17. Full HTTPS downloads of the ISO, source
  bundle, compliance manifest, `nex-core-local` package and `nex-controller` package matched the
  SHA-256 values above. Both the versioned and `latest` sidecars name the same hashes, and the
  public compliance manifest binds the final ISO and source bundle.
- The public APT `InRelease` has a good signature from the published Nex archive key. Its
  `Packages` index contains both 0.2.9 packages with the hashes above, the package payloads served
  from the indexed paths match those hashes, and `updates.json` advertises 0.2.9. The website
  service remained active and the remote staging directory was removed after verification.
