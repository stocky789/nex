## Executed local verification

- 93 focused release, source, packaging and APT publisher tests passed; `installer/check.sh`
  passed its source/syntax/offline-contract checks.
- The extracted Controller package starts with CGO support and an isolated SQLite database;
  integrity check passed with 16 tables, and its packaged UI returned HTTPS 200.
- Core and appliance contain the same product-source hash,
  `a18b1a4e79bdbfdeb4ab93884a1de157e89efa836775720af70cde36e76c31cf`. The standalone Controller's embedded source matches too.
- The final ISO has 1,262 package records; the appliance adds 323, for 1,585 components.
  Every ISO package hash and the complete package inventory match the manifest.
- Exact retained sources cover 573 required source/version pairs. All 573 source descriptors,
  their payload hashes, 2,459 retained files and checksums, and 729 notices passed verification.
  These notices include 725 package notices and four Nex notices.
- All three sidecars, final ISO/source manifest bindings and media `md5sum.txt` passed.
  Recipe verification matched 48 product-source and 69 media-source files against the build inputs.
- All 50 distinct firmware/bootloader package/version/hash tuples match the reviewed 0.2.9
  bytes. Against public 0.3.0, the only additional tuple is the previously reviewed
  `ovmf 2025.02-8+deb13u1`; `ovmf-generic 2026.05-2` is unchanged.
  The six excluded firmware packages and `virtio-win` media remain absent.
- Final ISO BIOS/KVM and UEFI/TCG menu captures were inspected: GUI, minimal text, serial
  console and rescue entries are present in both.

## Installation and publication

The exact ISO completed a BIOS/KVM offline installation on a new disposable disk, then first
boot and reboot. Serial output contained `NEX_SMOKE_INSTALL_PASS`,
`NEX_SMOKE_OVMF_2023_CERTIFICATES_PASS`, `NEX_SMOKE_ROOT_ONLY_PASS`,
`NEX_SMOKE_IDENTITY_PASS`, `NEX_SMOKE_FIRST_BOOT_PASS` and `NEX_SMOKE_REBOOT_PASS`.
The separate UEFI/TCG check covers its boot menu, not a UEFI installation.

Website/APT publication completed through the existing publishers. The versioned download
directory and `latest` now expose 0.3.1; previous retained releases were preserved and the
private upload staging directory was removed. The website service remained active.

Independent HTTPS downloads of the complete ISO, source bundle, manifest and both Debian
packages matched every hash and size in the table. Versioned and `latest` sidecars matched;
full payload verification used the versioned URLs. The public manifest binds the same ISO and
source hashes. The signed `InRelease` passed `gpgv` against both the published public key and
the archive key shipped with Nex. Its SHA-256 binds the downloaded `Packages` index, whose
0.3.1 entries bind the downloaded package payloads. `updates.json` agrees with those signed
package entries for version, filename, size and SHA-256.

Independent artifact/documentation review and the documentation/privacy/diff gates passed.
The exact release is available at [the ISO download](https://nexvirtualization.com/downloads/0.3.1/nex-core-0.3.1-amd64.iso)
and [matching sources](https://nexvirtualization.com/downloads/0.3.1/nex-core-0.3.1-source.tar.gz).

## Limits

No physical hardware, Secure Boot installation, new Windows installation or migration acceptance
is claimed. The boot/install harness uses disposable regular-file disks and no physical disks.
Hosted release CI and Git-forge publication were not run; this is a direct website/APT release.
API impact: none; distribution and evidence do not change Controller/Core contracts.
